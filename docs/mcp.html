VIBEMETRICS / MCP

Подключение MCP-клиента

Read-only stdio-мост для запросов к аналитике VibeMetrics. MCP-процесс работает рядом с порталом и обращается к API через loopback; отдельный публичный MCP-порт не нужен.

Инструменты

ИнструментЧто возвращает
list_projectsПроекты и их стабильные ID.
get_snapshotИтоги текущего и предыдущего периода, динамику по дням, атрибуцию, поведенческие фичи и до 100 последних событий.
export_csvCSV для проектов, атрибуции, дневных событий или поведенческих фич.

Фильтры: project — ID проекта; days — 7, 14 или 30; model — first или last. Для CSV дополнительно укажите dataset.

Подключение

Добавьте сервер в конфигурацию MCP-клиента, установленного на этом же сервере:

{
  "mcpServers": {
    "vibemetrics": {
      "command": "python3",
      "args": ["/opt/vibemetrics/selfhost/mcp_server.py"],
      "env": {
        "VM_API_URL": "http://127.0.0.1:18080",
        "VM_READ_TOKEN": "<read-token-from-server-env>"
      }
    }
  }
}

Значение VM_READ_TOKEN хранится в /opt/vibemetrics/.env. Не вставляйте токен в публичные страницы, репозиторий или сообщения агенту, доступные другим участникам.

Ограничения данных

Мост только читает данные. Он не создаёт события и не меняет проекты. CPA нельзя вычислить без данных о расходах; выручка и CRM-сделки доступны только в переданных источниках.

Поведенческие показатели описаны в определениях, возвращаемых API. Агенту следует указывать период и отличать события от сессий и уникальных посетителей. Пустой период означает отсутствие принятых событий, а не нулевую посещаемость сайта.
